How does it know it's unsure?
Every comment gets a score. Scores near the decision threshold are the risky ones.
unsure band → LLM
← clearly fine: allow
clearly harmful: block →
You set a budget, e.g. "send about 20% to the LLM".
Training turns it into the width of this band.
High-risk labels like self-harm use a lower floor:
any faint signal gets an LLM second opinion.
